# Event Submission Draft

## Project

AITRACEROOT V2 — AI Crypto Intelligence Terminal

## One-line pitch

A unified AI-native terminal that turns fragmented market, on-chain, wallet, risk and derivatives data into an actionable crypto research workflow.

## Problem

Researchers jump among charting tools, explorers, social feeds and spreadsheets. Data is abundant, but context is fragmented and verification is slow.

## Solution

AITRACEROOT connects discovery, token analysis, Smart Money, wallet intelligence, contract risk, futures context and an AI copilot in one responsive workspace.

## Innovation

The product is workflow-first rather than dashboard-first: every signal can lead into deeper token, wallet, risk or conversational investigation. Its private intelligence plane can orchestrate multiple providers while the public client stays fast, inspectable and credential-free.

## Technical highlights

- Modular ES-module frontend and installable PWA
- Same-origin private intelligence boundary
- Content-addressed, hardened production build
- Responsive terminal UI for desktop and mobile
- Safe rendering utilities and authenticated-route cache exclusions

## Current stage

Working product with implemented terminal surfaces, production build pipeline, tests and live-integration architecture. The public repository is a showcase edition; private provider orchestration is intentionally excluded.
