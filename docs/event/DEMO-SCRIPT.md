# Three-Minute Demo Script

## 0:00–0:25 — The problem

Show the terminal home. Explain that crypto research is fragmented across charts, explorers, wallet tools and social feeds.

## 0:25–1:05 — Discover and validate

Open Markets, select a token and demonstrate the transition from discovery to the token terminal. Highlight chart context, liquidity and asset identity.

## 1:05–1:45 — Follow the money

Open Smart Money and Wallet Intelligence. Demonstrate how wallet behavior adds context beyond price movement.

## 1:45–2:15 — Check risk

Open the Risk workspace and explain that opportunity discovery and downside checks belong in the same workflow.

## 2:15–2:40 — Ask the copilot

Use the AI assistant to summarize the investigation and propose the next verifiable research step. Avoid presenting generated content as financial advice.

## 2:40–3:00 — Close

Return to the dashboard. State the vision: one intelligence surface from discovery to decision, with the user retaining custody and final judgment.
