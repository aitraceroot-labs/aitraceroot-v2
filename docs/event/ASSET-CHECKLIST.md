# Submission Asset Checklist

- Project name and one-line pitch
- Public repository URL
- Live demo URL
- 2–3 minute landscape demo video
- 16:9 cover image
- Product screenshots for desktop and mobile
- Architecture diagram
- Team names, roles and contact details
- Supported chains and provider disclosures
- Clear statement of what was built during the event
- Roadmap and requested ecosystem support
- Final review of event eligibility and deadline
