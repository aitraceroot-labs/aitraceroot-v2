# Contributing

1. Create a focused branch.
2. Run `npm ci` and keep the lockfile intact.
3. Run `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build`.
4. Never add secrets, production data, private keys or deployment credentials.
5. Keep UI work accessible, responsive and usable without a wallet connection.

Changes should explain the user problem, the chosen trade-off and how the result was verified.
